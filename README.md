# Healthcare Appointment Data Analysis with Python & Pandas
## Project Overview
This project analyzes a synthetic healthcare appointment dataset using Python, Pandas, NumPy, and Matplotlib.
The analysis focuses on healthcare service patterns, including appointment status, department activity, city-wise visits, monthly trends, treatment costs, and patient satisfaction.
## Dataset
The project uses a synthetic healthcare appointment dataset containing appointment-level information such as:
- Appointment ID
- Appointment Date
- Patient Age
- Gender
- Department
- City
- Appointment Status
- Treatment Cost
- Payment Method
- Satisfaction Score

The dataset includes intentionally added missing values and duplicate records to demonstrate practical data-cleaning techniques.
No real patient information or personally identifiable health data is used in this project.

## Key Metrics
- **Total Appointments Analyzed:** 300
- **Total Treatment Cost:** 7,955,123
- **Average Treatment Cost:** 26,517.08
- **Average Satisfaction Score:** 3.10
- **Completed Appointment Rate:** 69.33%
## Key Findings
- Completed appointments were more common than cancelled and no-show appointments.
- Gynecology had the highest number of appointments among the departments.
- Kyoto recorded the highest number of visits among the listed cities.
- Gynecology generated the highest total treatment cost.
- Orthopedics had the highest average patient satisfaction score.
- October contained partial data, so the monthly trend for that month should be interpreted carefully.

# Healthcare Appointment Data Analysis using Python Pandas

## Project Overview
This project analyzes a healthcare appointment dataset using Python, Pandas, and Matplotlib.  
The goal is to explore appointment patterns, city-wise appointments, monthly trends, treatment costs, and patient satisfaction.

## Objectives
- Clean and prepare healthcare appointment data
- Analyze appointment trends
- Explore city-wise appointment distribution
- Visualize key healthcare service indicators
- Present findings for portfolio demonstration

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Key Analysis
- Data overview
- Data cleaning
- Exploratory Data Analysis (EDA)
- Appointment trend analysis
- Visualization using Matplotlib

## Project Files
- `Healthcare_Appointment_Data_Analysis_using_Python_Pandas.ipynb`

## Dataset
This project uses a synthetic healthcare appointment dataset created for learning and portfolio demonstration.
